App Store Reviews Scraper: Apple Ratings, Text & API

App Store reviews scraper for Apple iOS apps: ratings, text, authors, dates, versions and countries by app ID or link. Free filters and only-new tracking.

Run it on ApifyAll 23 TechLion Dev Actors$0.05 / 1,000 reviews

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Apple App Store Reviews Scraper collects customer reviews from any app on the Apple App Store into one clean table: star ratings, titles, review text, authors, dates, the app version the reviewer was using, and the country store the review came from. Paste App Store IDs or App Store links (or just the app's name), pick the countries you care about, and press Start.

It is for app marketers, support teams, app-store-optimization (ASO) researchers and AI (artificial intelligence) agents that need structured App Store reviews.

It reads Apple's public reviews feed and the iTunes lookup API (application programming interface) — the same public endpoints Apple publishes for every app. There is no browser, no login and no proxy, so runs are fast, cheap and reliable.

  • Watch competitor apps: schedule a daily run and get only the reviews you have not seen before.
  • Find complaints or praise: keep only 1–2 star or 4–5 star reviews, or reviews that mention a feature, a crash or a competitor.
  • Compare countries: scrape the United States, United Kingdom, Germany, Japan and more in one run, with a country column on every row.
  • Feed AI (artificial intelligence) tools, sentiment models and support queues with clean, structured review text.
  • Export a snapshot to Excel, CSV (comma-separated values) or JSON (JavaScript Object Notation).

What data does it extract?
🆔 Review ID, title and full review text ⭐ Star rating (1–5) and a sentiment label (positive, neutral, negative)
👤 Author name and public profile address 📅 Date (ISO 8601), weekday and age in days
🔢 App version the reviewer was using 🌍 Country code and country name
👍 Helpful votes (vote sum and vote count) 📱 App ID, app name and App Store link
🧑‍💻 Developer, category, price and currency 📊 App average rating and rating count in that country
🖼️ App icon 📝 Word count, sort order and the time the row was collected

Input

The only required field is Apps: one app per line. Any of these work:

  • An App Store ID: 389801252 (the number after /id in the app's address)
  • An App Store link: https://apps.apple.com/us/app/instagram/id389801252 (the country in the link is added for that app if it is not already in your country list)
  • An app name: WhatsApp Messenger (looked up in the first country you listed)

Example input:

{
    "apps": [
        "https://apps.apple.com/us/app/instagram/id389801252",
        "310633997",
        "Spotify"
    ],
    "countries": ["us", "gb", "de"],
    "maxReviews": 200,
    "sort": "mostRecent",
    "maxRating": 2,
    "since": "30 days",
    "onlyNew": true
}
Setting What it does
Countries Two-letter App Store codes such as us, gb, de, jp, br, in. Names such as United Kingdom also work.
Maximum reviews per app per country Stops after this many saved rows for each app in each country. Filtered-out reviews don't count.
Sort Most recent, or most helpful.
Filters (free) Keywords to keep or skip, minimum and maximum stars, only reviews posted since a date.
Only new reviews After the first run, save only reviews you have not seen before.

Apple's public reviews feed lists at most 500 reviews per app per country (50 per page, 10 pages). To collect more unique reviews, add more countries.

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Paste App Store IDs or links into Apps, and the countries you want into Countries.
  3. Set Maximum reviews per app per country and any filters. Filters are free.
  4. Click Start. The default run (30 reviews from each of 2 apps in 2 countries) usually finishes in a few seconds.
  5. Download your reviews from the Output tab, or connect them to another tool (see Integrations).

Monitoring new reviews on a schedule

Turn on Only new reviews, then create a schedule (for example every morning). The first run saves and remembers every review it finds. After that, each run saves only reviews that are new since last time, so a quiet day costs almost nothing. Use a different Tracking name for each separate watch list. Combine this with Only reviews posted since (for example 2 days) and Most recent sort to keep daily runs short.

Frequently asked questions

How do I find an app's App Store ID?

Open the app's page on the App Store (on the web or in the App Store app, use Share and copy the link). The ID is the number after /id in the address, for example 389801252 in https://apps.apple.com/us/app/instagram/id389801252. You can also paste the whole link, or just the app's name, and the Actor will look it up.

Can I scrape more than 500 reviews of one app?

Apple's public reviews feed lists at most 500 reviews for each app in each country store (10 pages of 50). That is an Apple limit, not a limit of this Actor. The practical way to collect more unique reviews is to add more countries: 3 countries can return up to 1,500 reviews of the same app, each row tagged with its country. A daily Only new reviews schedule will also accumulate history over time.

Is there an App Store reviews API I can call?

Yes, through this Actor. Every run is available through the Apify API (see the code examples above), so you get a reviews API with the same columns for every app and country, plus filters and new-review tracking.

Why are some reviews missing, or why did a country return none?

The app may not be sold in that country, Apple may have no public reviews for that store, or your filters (stars, keywords, date) may have removed every review. The exact reason is in RUN_SUMMARY. Those combinations are not charged when nothing is saved because the app was missing. Reviews removed by filters are also not charged.

Do I need an Apple account, an API key or a proxy?

No. The Actor uses only public Apple endpoints and runs on Apify's default infrastructure.

Is it legal to scrape App Store reviews?

The Actor reads only public review and app information that Apple publishes so customers can see it. It does not log in, post reviews or collect private account data. You are still responsible for how you use the data, so check the rules that apply to you.
