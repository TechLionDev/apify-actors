ISBN Lookup API: Book Metadata, Covers & ISBN-10/13

ISBN lookup API for books by ISBN-10, ISBN-13 or title: authors, publisher, pages, subjects and covers from Open Library, with a Google Books fallback.

Run it on ApifyAll 23 TechLion Dev Actors$0.50 / 1,000 books

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

ISBN Book Lookup turns an ISBN-10, an ISBN-13 or a book title into a clean row of metadata and cover images. It uses the official public Open Library catalog, and can fill gaps from Google Books when you add a free API key. Hyphens, ISBN: prefixes and links from Open Library or Amazon are understood, and an ISBN-10 is converted to ISBN-13 (and the other way around) when the check digit is valid.

It is for booksellers and librarians enriching a catalog, self-publishers and researchers checking editions, and developers or AI (artificial intelligence) agents that need book data without writing their own API client.

No browser, no login and no proxy: typical ISBN lookups finish in a few seconds, at $0.50 per 1,000 books found. Invalid ISBNs and misses are not charged.

  • Enrich a product or library catalog with title, authors, publisher, page count, subjects and covers.
  • Normalize mixed ISBN-10 and ISBN-13 lists, including hyphenated values and Amazon or Open Library links.
  • Search by title when you do not have an ISBN, and keep several matching editions.
  • Pull cover images in small, medium and large sizes, ready for a spreadsheet or a website.
  • Schedule a watch list of ISBNs and download the results as CSV, Excel or JSON.

What data does it extract?
📖 Title and subtitle ✍️ Authors
🏷️ ISBN-10 and ISBN-13 (with conversion and check-digit check) 🏢 Publisher, publication date and year
📄 Page count and language 🗂️ Subjects or categories
📝 Description or blurb 🖼️ Cover images (small, medium, large)
🔗 Open Library edition and work links 🆔 OCLC, LCCN and Goodreads IDs when present

Why this tool?

  • Cheap: $0.50 per 1,000 books found, a tiny start fee, and no charge for invalid ISBNs, misses or rows your filters drop.
  • Official catalogs: Open Library is the primary source. Google Books is an optional fallback if you provide your own free API key.
  • Clear output: one spreadsheet-friendly row per book, with the same columns every time, plus a run summary.
  • No login: nothing to configure for a basic ISBN or title lookup.

What it does not do: it does not scrape Amazon, Goodreads or retailer prices, and it does not download cover image files (it returns the image URLs). Retail listings and reviews are a different kind of tool.

Input

  • ISBNs, titles or links: one per line. ISBN-10, ISBN-13, hyphenated values, ISBN: 978…, and Open Library or Amazon book links are all accepted. Anything that is not an ISBN is treated as a title search.
  • Maximum results per title search (default 10): an ISBN always returns at most one edition.
  • Only keep books that were found (default on): invalid ISBNs and misses are dropped and never charged. Turn this off to keep a not-found row for every miss.
  • Only keep books with a cover image and Language filter are free. Filtered-out books are not charged.
  • Google Books API key (optional): used only to fill a missing description, rating or cover, or to look up an ISBN that Open Library does not have. There is no extra charge for using the key.

Example input:

{
    "queries": [
        "9780141439518",
        "9780451524935",
        "0061120081",
        "9780547928227"
    ]
}

Output

You get one row per book, with the same columns on every row. The dataset has three views: Overview, Identifiers and Covers. A RUN_SUMMARY record has the counts of books found, invalid ISBNs and misses.

How to use it

  1. Open the Actor in Apify Console and paste ISBNs or titles (or keep the sample list).
  2. Click Start. A short list finishes in a few seconds.
  3. Download the dataset as CSV, Excel or JSON, or open the Overview and Covers views.
  4. To run it on a schedule or from your own code, use the Apify API or an integration (see below).

Frequently asked questions

Do I need an API key?

No. Open Library is used by default and needs no key. A Google Books API key is optional and only used to fill gaps.

What happens if an ISBN is wrong?

The Actor checks the ISBN-10 and ISBN-13 check digits. An invalid number is reported as isbnValid: false with the reason "Invalid ISBN check digit" and is not charged. Turn off Only keep books that were found if you want those rows in the dataset.

Can I search by title instead of ISBN?

Yes. Any query that is not an ISBN is sent to Open Library search. Use Maximum results per title search to cap how many matching books are returned. Each saved book is charged the same as an ISBN lookup.

Are cover images downloaded?

No. The Actor returns cover URLs (small, medium and large). You can download the files in a later step if you need them stored.

Is it legal to look up this data?

Yes. The Actor reads public catalog APIs from Open Library (and optionally Google Books with your own key). It does not log in, bypass a paywall or scrape a retail site. You are responsible for how you use the results and for the terms of those catalogs.
