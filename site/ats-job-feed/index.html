Greenhouse, Lever, Ashby & Workday Jobs Scraper API

Greenhouse jobs scraper for Greenhouse, Lever, Ashby and Workday career pages. Salary columns, remote flags and new-job alerts. No login required.

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Greenhouse Jobs Scraper collects every open job from company career pages on Greenhouse, Lever, Ashby and Workday, plus Workable, SmartRecruiters and Recruitee. These hiring systems are also called applicant tracking systems, or ATS. It gives them back in one clean, identical table. Paste a list of careers links, pick filters if you want them, and get titles, locations, remote status, seniority, pay ranges, posting dates, apply links and full descriptions.

It is for recruiters, job-board builders, sales teams watching hiring signals, and AI (artificial intelligence) agents that need a Greenhouse jobs API, Lever jobs API or Workday jobs feed without building one from scratch.

It supports seven systems in one tool: Greenhouse, Lever, Ashby, Workable, SmartRecruiters, Recruitee and Workday. It reads the public job-board feeds these systems publish for exactly this purpose, so there is no browser, no login and no guesswork. Runs are fast, cheap and reliable.

  • Build a job board or newsletter: pull fresh jobs from hundreds of companies into one feed.
  • Watch target companies: schedule a daily run and get only the jobs that are new since yesterday.
  • Find sales leads from hiring signals: "this company just opened three data engineering roles."
  • Research pay: salary columns are filled from published pay ranges and from ranges written in the job text.
  • Feed AI agents and automations with structured, normalized job data.

What data does Greenhouse Jobs Scraper extract?
🏢 Company and board name 🧾 Job title and job ID
🎚️ Seniority (Intern, Entry, Mid, Senior, Lead, Manager, Director, Executive) 🗂️ Department and team
📍 Main location, all locations and country 🏠 Remote flag and workplace type (remote, hybrid, onsite)
⏱️ Employment type (Full-time, Part-time, Contract, Internship, Temporary) 💲 Pay range: minimum, maximum, currency, per year/month/hour
📅 Posted date and last updated date 🔗 Job link and apply link
📝 Full description as clean text (and HTML if you want it) 🆕 "New since last run" flag for scheduled runs

Why use it instead of other job scrapers?

  • More systems in one run. Most tools cover one to three systems. This one covers seven, including Workday, which most big companies use. Workday requests go through a residential proxy (ordinary home internet addresses) by default so the career site is less likely to block them; Greenhouse, Lever and the other systems stay direct and do not use the proxy.
  • All filters are free. Keyword, exclude, location, remote, department, employment type, seniority, posted-since and minimum pay filters never add to the price.
  • Clean salary columns. Pay is split into salaryMin, salaryMax, salaryCurrency and salaryPeriod, so you can sort and filter in a spreadsheet straight away.
  • Built for schedules. New-job tracking remembers what you already have and returns only new jobs.
  • Keeps going when one company fails. A wrong link is listed in the run summary and the rest of the run carries on.

Input

The only required field is Companies: one company per line. Any of these work:

  • A job board link: https://job-boards.greenhouse.io/stripe, https://jobs.lever.co/palantir, https://jobs.ashbyhq.com/ramp, https://apply.workable.com/huggingface/, https://jobs.smartrecruiters.com/ServiceNow, https://bunq.recruitee.com/
  • A Workday careers site link: https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite
  • The company's own careers page (the tool looks inside it for the job board behind it)
  • system:name, for example lever:palantir or greenhouse:figma
  • Just a name, like stripe (the tool tries each system until it finds a board with that name; Workday needs the full link)

Tip: how do I find a company's job board link? Open any job on the company's careers page. The address of the job page or of its "Apply" button usually contains greenhouse.io, lever.co, ashbyhq.com, workable.com, smartrecruiters.com, recruitee.com or myworkdayjobs.com.

Example input:

{
    "companies": [
        "https://job-boards.greenhouse.io/stripe",
        "https://jobs.lever.co/palantir",
        "ashby:ramp",
        "https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite"
    ],
    "keywords": ["engineer"],
    "excludeKeywords": ["intern"],
    "seniority": ["Senior", "Lead"],
    "locations": ["New York", "remote"],
    "postedSince": "14 days",
    "minSalary": 150000,
    "maxItems": 500,
    "onlyNewJobs": true
}

Each job is one row, in the same format for every system. You can download the data as Excel, CSV (comma-separated values), JSON (JavaScript Object Notation), XML or HTML, or read it through the Apify API (application programming interface).

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. In Companies, paste your list of careers links or board names.
  3. Add filters if you want them. They are all free.
  4. Click Start. A run with the default input finishes in about 10 seconds.
  5. Download your jobs from the Output tab, or connect the results to another tool (see Integrations below).

Frequently asked questions

How does new-job tracking work?

Turn on Mark jobs that are new since the last run or Only save new jobs. The Actor remembers which jobs it has returned for your company list (or for the tracking name you choose) and marks or keeps only the new ones. The first run counts every job as new. Jobs not seen for 180 days are forgotten.

Where does the salary come from?

Ashby, Lever and Recruitee include pay ranges when the company fills them in, and those are used first (salarySource = posted). When a system has no pay field, the Actor looks for a range written in the job text, such as "$150,000 - $200,000 per year" (salarySource = description). Greenhouse keeps structured pay on each job's own page, so turning on the Greenhouse salary lookup add-on reads it from there.

How is seniority worked out?

From the job title. For example "Senior" gives Senior, "Staff" or "Principal" gives Lead, "Intern" gives Intern, and "VP" or "Head of" gives Executive. Titles with no hint, like "Software Engineer", are left empty.

Are there limits on Workday?

Workday's public feed returns at most 2,000 jobs per search, and each saved Workday job needs its own detail request, so by default the Actor checks the newest 500 jobs per Workday company (change this with Workday jobs to check per company). If you set exactly one title keyword, the Actor searches for it on Workday's side, so even a narrow search reaches deep into very large boards.

Workday career sites often block requests from cloud servers with "HTTP 429" (too many requests). By default, Workday requests go through Apify's residential proxy (ordinary home internet addresses) so this is much less likely. Other hiring systems never use the proxy. You can turn the proxy off in the input if you want to try without it. There is also a hard cap on estimated proxy traffic per run (50 megabytes by default, at most 100). When the cap is reached, the Actor stops fetching more Workday jobs, keeps what it already saved, and continues with any other companies.

Workday jobs are charged as a separate, higher event (see the Pricing tab) so the proxy cost is covered and does not eat into the regular job price.

Why do Workday jobs cost more?

Workday is the one system in this Actor that usually needs a residential proxy to work reliably from Apify's servers. The proxy is billed by how much data goes through it. The Workday job event is priced to cover that cost, with a margin, so a busy Workday run does not turn into a loss. Greenhouse, Lever, Ashby and the other systems stay at the regular job price.

Why did a company fail?

The board name may be wrong, the company may have closed its board, or it may use a system this Actor does not support yet. The run summary shows the exact reason for each company. Open an issue and we will look at adding the system.

Is it legal to collect this data?

The Actor reads only public job postings that companies publish so that people can find and apply to them. It does not log in or collect personal data about candidates. You are still responsible for how you use the data, so check the rules that apply to you.

Is there a Greenhouse jobs API or Lever jobs API I can call?

Yes. Every run of this Actor is available through the Apify API (see the code examples above), so you can treat it as one jobs API for Greenhouse, Lever, Ashby, Workday, Workable, SmartRecruiters and Recruitee. You send a list of companies and get back the same columns for every system.

Can I scrape a company's career page if I don't know which system it uses?

Yes. Paste the company's own careers page or just its name. The Actor looks for the job board behind the page and tries each supported system, and the run summary tells you which system it found.

How is this different from a LinkedIn or Indeed jobs scraper?

Job sites like LinkedIn and Indeed copy jobs from company career pages, often days later and with missing pay data. This Actor reads the company's own job board directly, so jobs show up as soon as they are posted and with the pay range the company published.
