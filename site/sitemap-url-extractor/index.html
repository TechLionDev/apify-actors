Sitemap URL Extractor: All Pages, SEO Check & Monitor

Sitemap extractor: get every URL from a website's sitemap.xml, with dates and images. Optional page check finds broken links and SEO problems.

Run it on ApifyAll 23 TechLion Dev Actors$0.30 / 1,000 URLs

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Sitemap Extractor (also called Sitemap URL Extractor) gets every page address a website lists in its sitemaps, including sitemap.xml, and puts them in one clean table, with last-modified dates, images, language versions and news details. Give it a website and it finds the sitemaps for you, including sitemap indexes, gzipped files and plain-text sitemaps. Turn on the page check add-on to visit each page and find broken links, redirects and SEO (search engine optimization) problems, or schedule it to get new, changed and removed pages.

It is for SEO specialists, site owners and developers who need a full URL list from a sitemap, a broken-link check, or a change monitor.

  • SEO audits: list every page a site shows search engines, then check status codes, titles, descriptions, canonical links and noindex tags.
  • Broken link reports: find sitemap pages that return errors or redirect.
  • Competitor monitoring: get new product, pricing or blog pages as soon as they appear.
  • Feed other tools: give a complete URL list to a crawler, an AI (artificial intelligence) tool or a content inventory.
  • Site migrations: compare old and new URL lists and catch missing pages.

What data does it extract?
🔗 Page URL, host, path, folder and file type 📅 Last-modified date and days since it changed
🔁 Change frequency and priority 🖼️ Images listed for the page
🌍 Other language versions (hreflang) 📰 News article titles and publish times
🗂️ Which sitemap file it came from 🆕 New, modified or removed (change monitoring)
🩺 HTTP status, redirects, final URL and response time (add-on) 🏷️ Title, meta description, H1 heading and word count (add-on)
🧭 Canonical link, noindex tag and language (add-on) 🚩 Broken and problem page flags (add-on)

Why this tool?

  • Finds sitemaps automatically from robots.txt and the usual locations, and follows nested indexes up to 1,000 sitemap files.
  • Fast and cheap: thousands of URLs in a few seconds, with no browser.
  • Built-in SEO check as an optional add-on, with a "problems only" mode for quick audits.
  • Change monitoring with new, modified and removed pages.
  • Free filters: text to keep or skip, a regular expression (pattern) and a modified-since date. Filtered-out URLs are never charged.

Input

{
    "startUrls": ["https://apify.com", "https://blog.apify.com/sitemap.xml"],
    "maxUrlsPerSite": 200
}

An SEO audit that saves only broken pages, redirects and other problems:

{
    "startUrls": ["https://example.com"],
    "maxUrlsPerSite": 2000,
    "urlExcludes": ["/tag/"],
    "checkPages": true,
    "onlyProblemPages": true
}

Main options:

  • Websites or sitemaps: website addresses or direct sitemap links, and a limit per website.
  • Filters (free): URL contains, URL does not contain, URL pattern (regular expression) and modified since (for example 7 days).
  • Page check add-on ($): check each page, optionally save only problem pages, and set how many pages to check at once.
  • Change monitoring: track changes between runs, save only changes, and a memory name.

Output

One row per URL. The Overview view shows addresses and dates, Page checks shows status and SEO fields, and Changes shows new, modified and removed pages. Download as Excel, CSV (comma-separated values), JSON (JavaScript Object Notation), XML or HTML.

How to use it

  1. Click Try for free.
  2. Add websites (https://example.com) or sitemap links (https://example.com/sitemap.xml).
  3. Add filters, and turn on Check each page for an SEO audit.
  4. Click Start. The default input finishes in a few seconds.
  5. Download the list, or schedule the run with Track changes between runs.

Monitoring a site for changes

  1. Turn on Track changes between runs, keep Save only changes on, and schedule the run (for example daily).
  2. The first run marks every URL as new and remembers the list.
  3. Every later run saves only pages that are new, modified (their sitemap date changed) or removed.
  4. Connect the run to email, Slack or a webhook to get alerts.

Frequently asked questions

How does it find the sitemaps?

It reads the website's robots.txt, then tries the usual addresses such as /sitemap.xml, /sitemap_index.xml and /wp-sitemap.xml. You can also give sitemap links directly.

The site has no sitemap. What happens?

The run summary lists it as no_sitemap_found. This tool does not crawl pages to find links.

What counts as a problem page?

A page that returns an error (400 or higher) or no response, redirects, has a noindex tag, has a canonical link pointing to another page, or has no title.

Will page checks overload a website?

Pages are checked 5 at a time by default with a simple, honest user agent. Lower Pages to check at once for small websites.

Is it legal?

Sitemaps are published by websites so that machines can read them. The page check only loads public pages, like a browser would. Respect each website's terms.

Can I get all the pages of a website without crawling it?

Yes. Most websites publish a sitemap that lists every page they want search engines to find. This Actor reads all of them (including sitemap index files and compressed sitemaps), so you get the full list in seconds instead of crawling page by page.

Can it find broken links and redirects?

Yes. Turn on the Check each page ($) add-on and every listed page is visited once to record its status code, redirects, page title, meta description and canonical tag. Turn on Only save pages with problems to keep just the pages that need fixing.
