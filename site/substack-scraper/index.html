Substack Scraper: Newsletter Posts, Full Text & Comments

Substack newsletter scraper: posts, full text as Markdown, likes, comments, paywall status and subscriber counts. Free filters and new-post tracking.

Run it on ApifyAll 23 TechLion Dev Actors$0.50 / 1,000 posts

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Substack Newsletter Scraper (also called Substack Scraper) collects posts from any Substack newsletter, including newsletters on their own domain (like lennysnewsletter.com), into a clean table. Get titles, dates, authors, likes, comments, restacks, paywall status and subscriber estimates, plus optional full text (as plain text, HTML or Markdown) and public comments. No login and no API (application programming interface) key needed.

It is for media researchers, newsletter operators, sponsor teams and AI (artificial intelligence) pipelines that need Substack posts and full text in one place.

  • Research creators and niches: compare newsletters by subscribers, likes and comments per post.
  • Build reading lists and archives: export a newsletter's full public history.
  • Feed AI tools: get full text as Markdown for summaries, search or RAG (retrieval-augmented generation).
  • Monitor topics: keep only posts that mention your keywords and get new ones on a schedule.
  • Find sponsors and partners: spot fast-growing, highly engaged newsletters in your space.

What data does Substack Newsletter Scraper extract?
📰 Newsletter name, link and subscriber estimate 🧾 Post title, subtitle, link and ID
📅 Publish date ✍️ Authors (name and handle)
🔒 Audience: free or paid, and a paywall flag ❤️ Likes, 💬 comment count and 🔁 restacks
⏱️ Word count and reading time 🏷️ Section and tags
🖼️ Cover image 🎧 Podcast audio link and length
📄 Full text as text, HTML or Markdown (add-on) 💬 Public comments with author, date and likes (add-on)

Why this scraper?

  • Low price per post and only a tiny start fee (see pricing below).
  • Free filters: date range, keywords, words to skip, free or paid, post type and minimum likes.
  • Subscriber estimates and reading time on every row at no extra cost.
  • New-post tracking for scheduled runs, so you never pay twice for the same post.
  • Markdown output ready for AI tools.

Input

Add newsletters one per line: the short name (astralcodexten), the newsletter address (https://www.lennysnewsletter.com), or a single post link (https://www.lennysnewsletter.com/p/some-post).

{
    "publications": ["https://www.lennysnewsletter.com", "astralcodexten"],
    "maxPostsPerPublication": 100,
    "newerThan": "90 days",
    "includeKeywords": ["AI", "growth"],
    "access": "free",
    "minLikes": 50,
    "includeFullText": true,
    "includeMarkdown": true,
    "maxCommentsPerPost": 20
}

Output

One row per post. The Overview view shows engagement, Full text shows the body, and Newsletter stats shows subscriber estimates next to each post.

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Add one or more newsletters or post links.
  3. Choose filters and add-ons.
  4. Click Start. The default input finishes in about 15 seconds.
  5. Download the posts from the Output tab, or connect them to another tool.

Frequently asked questions

Does it get the full text of paid posts?

No. For paid (subscriber-only) posts, Substack publicly shows only the free preview, so that is what you get. The isPaywalled and isFullTextComplete fields tell you which is which.

Do custom domains work?

Yes. Newsletters on their own domain, like www.lennysnewsletter.com, work the same way as name.substack.com addresses.

Where does the subscriber number come from?

From the subscriber count the newsletter itself shows publicly, such as "Over 1,200,000 subscribers". Some newsletters hide it, and then the field is empty.

How does new-post tracking work?

With Only save posts that are new since the last run on, the scraper remembers the newest post of each newsletter and next time stops as soon as it reaches it. You only get, and pay for, new posts.

Is it legal to scrape Substack?

The scraper reads only public pages that anyone can open without logging in. Comments can contain names and personal opinions, so make sure you have a legitimate reason to collect and use them under the privacy laws that apply to you, and respect authors' copyright when reusing text.

Can I use this as a newsletter scraper for many Substacks at once?

Yes. Add as many publications as you like (names, links or custom domains). Each row says which newsletter it came from, so one run can track a whole list of newsletters.

Can I feed Substack posts into an AI tool?

Yes. Turn on Full text of each post and Also give the full text as Markdown to get each post's full text in a format that AI (artificial intelligence) tools and language models read well, with headings and links kept.
