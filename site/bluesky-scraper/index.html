Bluesky Scraper: Posts, Profiles, Replies & Hashtags

Bluesky scraper: posts by keyword, hashtag, profile or post link with likes, reposts, replies, images, links and author followers. No login, free filters.

Run it on ApifyAll 23 TechLion Dev Actors$0.30 / 1,000 posts

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Bluesky Scraper collects public Bluesky posts into one clean table: post text, likes, reposts, replies, quotes, hashtags, links, images, videos and the author's handle, follower count and bio. Search by keyword or hashtag, list the profiles you want to follow, or paste a post link to get the post and every reply.

It is for social media managers, marketers, journalists, researchers and AI (artificial intelligence) agents that need structured Bluesky data.

It reads Bluesky's official public API (application programming interface), the same open AT Protocol endpoints the Bluesky app uses for logged-out visitors. There is no browser, no login, no app password and no proxy, so runs are fast, cheap and reliable.

  • Monitor your brand, product or competitors: schedule a search and get only posts you have not seen before.
  • Track hashtags and topics: collect thousands of posts for a keyword, hashtag or phrase, newest first.
  • Follow accounts: save every post from a list of profiles, with engagement numbers.
  • Export full conversations: paste a post link to get the post and all replies, with reply depth.
  • Feed AI tools, dashboards and sentiment models with clean, structured post text.

What data does it extract?
📝 Post text, link, ID and AT Protocol address 📅 Date (ISO 8601), weekday and age in hours
❤️ Likes, reposts, replies, quotes and total engagement 🌐 Post languages
👤 Author handle, display name, avatar and profile link 📈 Author followers, following, post count, bio, join date and blue check
#️⃣ Hashtags, mentions and links 🖼️ Image links and alt text, video stream and thumbnail
🔗 Link card (address, title, description) 💬 Reply-to post, thread root, thread depth, quoted post and its text
🔁 Repost and pinned-post flags 🏷️ Moderation labels, word count and the source that found the post

Input

Use any mix of these sources. Each one is collected separately, up to Maximum posts per source.

  • Search terms: AI agents, #buildinpublic, "local seo". Bluesky search syntax works too, such as from:bsky.app or domain:example.com.
  • Profiles: bsky.app, @jay.bsky.team, https://bsky.app/profile/bsky.app (a name without a dot gets .bsky.social added).
  • Post links: https://bsky.app/profile/bsky.app/post/3l6oveex3ii2l saves the post and every reply.

Example input:

{
    "searchTerms": ["AI agents", "#buildinpublic"],
    "profiles": ["bsky.app"],
    "postUrls": ["https://bsky.app/profile/bsky.app/post/3l6oveex3ii2l"],
    "maxPostsPerSource": 500,
    "sort": "latest",
    "languages": ["en"],
    "since": "7 days",
    "minLikes": 2,
    "onlyNew": true
}
Setting What it does
Search order Latest (newest first, can go thousands deep) or Top (most popular; Bluesky returns at most 100 per term to logged-out visitors)
Include replies Keep replies in search and profile results (on by default)
Include reposts on profiles Also save posts a profile reposted, with who reposted them
Languages, dates, keywords, minimum likes, only with media Free filters. Removed posts are not charged
Add author follower counts and bio On by default, free
Only new posts + Tracking name Save only posts not seen in earlier runs

Output

You get one row per post. Every row has the same columns, so the data drops straight into a spreadsheet. The dataset has three views: Overview, Authors and Media & links. A RUN_SUMMARY record lists each source with posts seen, posts saved and any error.

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Add search terms, profiles or post links.
  3. Set Maximum posts per source and any filters. Filters are free.
  4. Click Start. The default run (25 posts for one search and 25 from one profile) finishes in a few seconds.
  5. Download the posts from the Output tab as Excel, CSV (comma-separated values) or JSON (JavaScript Object Notation), or connect them to another tool.

Monitoring Bluesky on a schedule

Turn on Only new posts, then create a schedule (for example every hour). The first run saves and remembers every post it finds. After that, each run saves only posts that are new since last time, so a quiet hour costs almost nothing. Use a different Tracking name for each separate watch list, and add Only posts since (for example 2 days) to keep runs short.

Frequently asked questions

Do I need a Bluesky account, an app password or an API key?

No. The Actor uses Bluesky's public API for logged-out visitors and runs on Apify's default infrastructure. You never share your Bluesky login.

How many posts can I get for one search term?

With Latest order, the Actor keeps moving back in time, so a busy term can return thousands of posts (set Maximum posts per source up to 20,000). With Top order, Bluesky returns at most 100 posts per term to logged-out visitors.

Why were some posts skipped?

Some people ask Bluesky not to show their posts to logged-out visitors. The Actor respects that and skips those posts; the count is in the status message and in RUN_SUMMARY. Your filters (dates, languages, keywords, minimum likes) can also remove posts. Skipped posts are never charged.

Can I get all replies to a post?

Yes. Paste the post link into Post links. You get the post and every reply, with threadDepth (1 = direct reply, 2 = reply to a reply, and so on) and replyToUrl.

Can I search for a hashtag?

Yes. Enter it with the #, for example #photography. The Actor uses Bluesky's tag filter, so you get posts that use that hashtag.

Is it legal to scrape Bluesky?

The Actor reads only public posts and profiles through Bluesky's own public API, the same data anyone can see without logging in, and it skips accounts that opted out of logged-out visibility. It does not log in, post, like or follow. You are still responsible for how you use the data (for example under privacy laws such as GDPR), so check the rules that apply to you.
