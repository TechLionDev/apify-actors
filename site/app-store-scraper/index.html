App Store Scraper API: Apple App Details, Search & Charts

Apple App Store scraper API: ratings, rating counts, price, category, version, dates and screenshots by keyword, app, developer or top chart. No login.

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

App Store Scraper collects app data from the Apple App Store into one clean table: app name, developer, star rating, number of ratings, price, category, age rating, current version and release notes, first release and last update dates, download size, languages, icon, screenshots and the full description. Find apps by keyword search, app link or ID, developer, or Apple's live top charts (top free, top paid, top grossing and new apps, by category), in any country.

It is for app marketers, ASO (App Store Optimization) specialists, indie developers, investors, agencies, market researchers and AI (artificial intelligence) agents.

It reads Apple's official public iTunes Search and Lookup endpoints and the App Store chart feeds. There is no browser, no login and no proxy, so runs are fast, cheap and reliable.

  • Track competitors: ratings, rating counts, versions and release notes for any list of apps, in many countries.
  • Monitor top charts daily by category and spot new apps entering the chart.
  • Research a niche: search a keyword and see every app with its rating, size of audience (rating count) and price.
  • Find leads: developers and their websites for apps in a category (great for agencies and SDK (software development kit) vendors).
  • Feed AI tools with clean app descriptions and metadata.

Input

Use any mix of these sources. Each one is read for every country and saved up to Max apps per source.

  • Search terms: any keyword (Apple returns up to about 200 apps per search).
  • App links or IDs: https://apps.apple.com/us/app/instagram/id389801252, 389801252 or a bundle ID like com.spotify.client.
  • Developer links or IDs: https://apps.apple.com/us/developer/google-llc/id281956209 or 281956209.
  • Top charts: top free, top paid and top grossing (iPhone or iPad), new apps, new free apps, new paid apps, with optional categories.

Example input:

{
    "searchTerms": ["habit tracker", "budget planner"],
    "apps": ["https://apps.apple.com/us/app/instagram/id389801252", "com.spotify.client"],
    "developers": ["281956209"],
    "charts": ["topfree", "topgrossing"],
    "chartCategories": ["all", "productivity", "healthandfitness"],
    "countries": ["us", "gb", "de"],
    "maxAppsPerSource": 100,
    "minRatingsCount": 100,
    "updatedSince": "180 days"
}
Setting What it does
Countries Two-letter App Store codes (us, gb, de, fr, jp...). Prices, ratings and charts are local
Top chart categories Read each chart for all categories or for specific ones (Games, Productivity...)
Minimum rating / number of ratings Free quality filters
Price Free and paid, free only, or paid only
First released since / last updated since A date (2026-01-31) or a relative value (30 days, 6 months)
Categories, include / exclude words Keep only apps in these categories or with these words
Only new apps + Tracking name Save only apps not seen in earlier runs

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Add search terms, app links, developers or top charts, and the countries you care about.
  3. Set Max apps per source and any filters. Filters are free.
  4. Click Start. The default run (a "habit tracker" search, 50 apps) finishes in a few seconds.
  5. Download the results from the Output tab as Excel, CSV (comma-separated values) or JSON (JavaScript Object Notation), or connect them to another tool.

Chart and competitor monitoring

Pick the charts and categories (or list your competitors' app links), then create a schedule (for example every day). Without tracking you get a full daily snapshot, ideal for rank history. With Only new apps on, you get only apps that newly entered the chart or search.

Frequently asked questions

Do I need an Apple account or API key?

No. The Actor uses Apple's official public iTunes Search and Lookup endpoints and the public App Store chart feeds. It runs with no login and no proxy.

How many apps can I get per search or chart?

Apple returns up to about 200 apps per keyword search and up to 100 apps per top chart (per category and country). Add more keywords, categories or countries to get more apps.

Does it include reviews or download numbers?

Apple does not publish download numbers; the number of ratings is the best public signal of an app's audience. For review text, use our Apple App Store Reviews Scraper with the app IDs from this Actor.

Why does the same app appear more than once?

Each row belongs to one source and one country, so an app found by two searches or in two countries appears in each, with its local price, rating and rank. Remove duplicates by appId (and country) if you need one row per app.

Can I track chart positions over time?

Yes. Schedule the Actor daily with the charts you care about. Every row has the rank, country, source and scrapedAt columns, so you can build rank history in a spreadsheet or database.

Is it legal to scrape the App Store?

The Actor reads only public app information through endpoints Apple publishes for developers and affiliates. It does not log in, download apps or collect personal data. You are responsible for how you use the data, so check the rules that apply to you.
