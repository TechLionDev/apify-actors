Telegram Channel Scraper: Posts, Views & Links, No Login

Telegram channel scraper with no login: posts, views, reactions, engagement, media, links and channel stats. Free filters and new-post tracking.

Run it on ApifyAll 23 TechLion Dev Actors$0.50 / 1,000 posts

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Telegram Scraper (a Telegram channel scraper) collects posts from public Telegram channels into a clean table, with no Telegram account, phone number or API (application programming interface) key. Paste channel names, press Start, and download text, dates, views, reactions, photos, videos, links, hashtags, mentions and emails as Excel, CSV (comma-separated values) or JSON (JavaScript Object Notation).

It is for journalists, brand-monitoring teams, researchers and AI (artificial intelligence) agents that need Telegram posts, views and reactions without a Telegram login.

It reads the same public web preview anyone can open in a browser at t.me/s/<channel>. It does not log in, join channels, or read private groups or chats.

  • Track news and announcements from crypto projects, brands, media and communities that publish on Telegram.
  • Benchmark channels: compare views, reactions and engagement rate per post.
  • Monitor keywords: keep only posts that mention your brand, a token or a topic.
  • Collect leads and links: pull out every link, @mention and email address written in posts.
  • Run it on a schedule and get only the posts published since the last run.

What data does Telegram Scraper extract?
📝 Full post text, with line breaks 📅 Publish date and edited flag
👁️ Views (as a number and as shown, like 48.2K) ❤️ Every reaction and the total reaction count
📈 Engagement rate (views as % of subscribers) 🖼️ Photo, video and video thumbnail links
🏷️ Post type: text, photo, video, document or poll #️⃣ Hashtags, @mentions and email addresses
🔗 Links in the text and the link preview card ↪️ Forwarded-from channel and reply-to post
📣 Channel name, subscribers and verified badge 📁 Channel profile: description and media counts

Why this scraper?

  • Cheapest per post among popular Telegram scrapers, with a tiny start fee (see pricing below).
  • All filters are free: date range, keywords, words to skip, post type, minimum views and links-only.
  • New-post tracking built in: schedule it hourly or daily and pay only for new posts.
  • Clean extras for free: hashtags, mentions, emails, total reactions and engagement rate on every row.
  • Robust: a private or missing channel is noted in the run summary and the run carries on.

Input

Add channels one per line, in any of these forms: durov, @durov, https://t.me/durov, or a post link like https://t.me/durov/300 to start at that post and go back in time.

{
    "channels": ["durov", "telegram"],
    "maxPostsPerChannel": 200,
    "newerThan": "30 days",
    "includeKeywords": ["wallet", "update"],
    "excludeKeywords": ["giveaway"],
    "mediaTypes": ["text", "photo"],
    "minViews": 100000,
    "onlyNewPosts": true
}

Output

One row per post. The Overview view shows engagement at a glance, Links and contacts shows links, mentions and emails, and Media lists photos, videos and files.

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Add one or more public channel names or links.
  3. Set the number of posts and any filters.
  4. Click Start. The default input finishes in a few seconds.
  5. Download the posts from the Output tab or connect them to another tool.

Frequently asked questions

Do I need a Telegram account?

No. The scraper reads the public web preview of each channel, so there is nothing to log in to and your account can never be banned.

Which channels work?

Public channels that have a web preview at t.me/s/<channel>, which is nearly all public channels. Private channels, groups and direct chats do not work.

How does new-post tracking work?

With Only save posts that are new since the last run on, the scraper remembers the newest post of each channel. Next time it stops as soon as it reaches that post, so you get, and pay for, only new posts.

Can I get comments?

Not yet. Comments on Telegram live in linked discussion groups that need an account to read. Open an issue if you need them.

Is it legal to scrape Telegram?

The scraper only reads posts that channels publish publicly for anyone to see. Posts can still contain personal data such as names or emails, so make sure you have a legitimate reason to collect and use it under the privacy laws that apply to you.

Is there a Telegram scraper that works without the Telegram API?

Yes, this one. It reads the public web preview that Telegram shows for every public channel, so you don't need an API (application programming interface) ID, a phone number or a Telegram account.

Can I monitor several Telegram channels every hour?

Yes. Put all channel names in one run, turn on Only save posts that are new since the last run, and add a schedule. Each run returns only posts published since the last run, so you pay only for new posts.
