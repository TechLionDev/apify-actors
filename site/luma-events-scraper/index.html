Luma Events Scraper: Events, Hosts, Tickets & Guest Counts

Luma events scraper for lu.ma: search by city, category or calendar for dates, venues, prices, sold-out status, guest counts and host contacts. No login.

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Luma Events Scraper is a Luma event scraper for lu.ma and luma.com, the event platform used by tech, AI (artificial intelligence), crypto and startup communities. Search by city, category, community calendar or event link, and get dates, venues, prices, sold-out status, guest counts and host contact handles in a clean table. No login and no API (application programming interface) key needed.

It is for event marketers, community managers, sponsorship teams and anyone building a Luma events feed or host lead list.

  • Find events to attend or sponsor in any city, filtered by topic and date.
  • Build event newsletters and calendars from a few community calendars.
  • Generate leads: host names, websites and social handles for organizers in your niche.
  • Track the market: see which communities run the biggest events and how fast they sell out.
  • Get alerts: schedule it and receive only newly announced events.

What data does Luma Events Scraper extract?
🎟️ Event name, link and ID 📅 Start and end time, local start time, day and length
📍 Venue, full address, city, country and coordinates 💻 In person or online
💲 Free flag, ticket price range and currency 🚦 Sold out, spots left, waitlist and approval needed
👥 Guest count 🗓️ Community calendar name and link
🙋 Hosts with website, X (Twitter), LinkedIn and Instagram handles 🖼️ Cover image
📝 Full description and categories (add-on) 🎫 Ticket types with prices and capacity (add-on)

Why this scraper?

  • Every way in: cities, categories near any of 70+ cities (or any coordinates), community calendars and single event links.
  • Free filters: date window, keywords, words to skip, in person or online, free only, still available and maximum price.
  • Lead-ready host columns: host names, websites and social handles flattened into simple columns.
  • New-event tracking for scheduled runs, so you never pay twice for the same event.
  • Readable times: local start time and day of the week in the event's own time zone.

Input

Use any mix of these:

  • Cities: Luma's short city names, like sf, nyc, london, berlin, singapore.
  • Categories: tech, ai, crypto, food, arts, climate, fitness, wellness, with a Location for categories (a city name or coordinates like 40.71,-74.00).
  • Calendar or event links: for example https://lu.ma/genai-sf for all upcoming events of a community, or a single event link.
{
    "cities": ["sf", "nyc"],
    "categories": ["ai"],
    "categoryLocation": "london",
    "startsBefore": "14 days",
    "includeKeywords": ["AI", "founders"],
    "locationTypes": ["offline"],
    "onlyAvailable": true,
    "maxEventsPerSource": 100,
    "onlyNewEvents": true
}

One row per event. The Overview view shows the essentials, Hosts and organizers shows contact columns, and Full details shows everything.

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Add cities, categories or calendar links.
  3. Set the date window and any filters.
  4. Click Start. The default input finishes in a few seconds.
  5. Download the events from the Output tab, or connect them to another tool.

Frequently asked questions

Which cities work?

Any city Luma has a page for. Use the short name from the city page address, such as sf, nyc, la, london, paris, berlin, singapore, tokyo or bangalore. For categories, you can give a city name from a list of 70+ cities, or exact coordinates.

Does it get past events or attendee lists?

No. It collects upcoming public events and the public guest count. It does not read guest lists or anything behind a login.

Why are some addresses missing?

Some hosts hide the exact address until you register. Those events show addressVisibility and only the city.

How does new-event tracking work?

With Only save events not seen in earlier runs on, the scraper remembers which events your search returned before and saves only new ones next time. Events that ended over 30 days ago are forgotten.

Is it legal to scrape Luma?

The scraper reads only public event pages anyone can see without logging in. Host names and social handles are public, business-related information, but you are still responsible for using them in line with the privacy and anti-spam laws that apply to you.

Can I get every tech or AI event in my city from Luma?

Yes. Pick your city (for example sf, nyc, london or berlin) and, if you like, a category such as AI or crypto. Turn on Only save events not seen in earlier runs and schedule a daily run to get a fresh list of upcoming events each morning.

Can I use Luma events for lead generation?

Yes. Each event lists its hosts with their public profile handles, and the guest count shows how big each community is, so sponsors, venues and sales teams can find active organizers.
