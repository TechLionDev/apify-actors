Trustpilot Reviews Scraper API: Ratings, Replies, TrustScore

Trustpilot reviews scraper API: stars, titles, text, dates, verified status, company replies and TrustScore by website or link. Free filters. No login.

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Trustpilot Reviews Scraper collects customer reviews of any company on Trustpilot into one clean table: star ratings, titles, review text, dates, verified status, reviewer country, the company's reply and how long it took, plus the company's TrustScore, categories and published contact details. Paste company websites or Trustpilot links and press Start.

It is for marketing, customer experience and support teams, e-commerce sellers, agencies, investors, researchers and AI (artificial intelligence) agents that need structured Trustpilot reviews.

It reads the same public review pages any visitor sees on Trustpilot, without logging in. A real browser passes Trustpilot's bot check once, then pages are read quickly from inside it.

  • Monitor your brand or competitors: schedule a daily run and get only the reviews you have not seen before.
  • Find complaints or praise: keep only 1–2 star or 4–5 star reviews, verified reviews, or reviews that mention a product or a problem.
  • Measure reply quality: see which reviews got a company reply and how many hours it took.
  • Build lead lists: every row carries the company's TrustScore, category, website, phone and address when Trustpilot publishes them.
  • Export to Excel, CSV (comma-separated values) or JSON (JavaScript Object Notation).

What data does it extract?
🆔 Review ID, review link, title and full text ⭐ Star rating (1–5) and a sentiment label
📅 Published date, experience date, weekday and age in days ✅ Verified status, verification level and review source
💬 Company reply, reply date and reply delay in hours 👤 Reviewer name, country, review count and profile link
🏢 Company name, domain, website and Trustpilot page 📊 TrustScore, star rating and total review count
🗂️ Main category and all categories 📞 Company email, phone and address (when published)

Input

The only required field is Companies: one per line. Any of these work:

  • A website: zappos.com or www.chewy.com
  • A Trustpilot link: https://www.trustpilot.com/review/www.amazon.com
  • A country Trustpilot link: https://uk.trustpilot.com/review/www.argos.co.uk

Example input:

{
    "companies": ["www.zappos.com", "https://www.trustpilot.com/review/www.chewy.com"],
    "maxReviews": 500,
    "sort": "recency",
    "stars": ["1", "2"],
    "language": "en",
    "datePeriod": "last3months",
    "onlyNew": true
}
Setting What it does
Maximum reviews per company Stops after this many saved rows per company (up to 2,000). Filtered-out reviews don't count.
Sort Newest first, or Trustpilot's most relevant order.
Filters (free) Star ratings, review language, date period, only reviews since a date, verified only, with company replies only, keywords to keep or skip.
Only new reviews After the first run, save only reviews you have not seen before.

Trustpilot shows logged-out visitors 10 pages (200 reviews) per filter. Above 200, the Actor reads up to 200 reviews for each star rating, so a company can return up to 1,000 reviews per run (or 200 per star value you choose). For companies with more reviews, combine different languages or date periods, or schedule Only new reviews to build history over time.

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Paste company websites or Trustpilot links into Companies.
  3. Set Maximum reviews per company and any filters. Filters are free.
  4. Click Start. The default run (50 reviews from each of 2 companies) takes about 20 seconds.
  5. Download your reviews from the Output tab, or connect them to another tool (see Integrations).

Monitoring new reviews on a schedule

Turn on Only new reviews, then create a schedule (for example every morning). The first run saves and remembers every review it finds. After that, each run saves only reviews that are new since last time. Use a different Tracking name for each separate watch list, and combine it with Newest first and Only reviews posted since (for example 3 days) to keep daily runs short.

Frequently asked questions

How do I find a company on Trustpilot?

Paste the company's website (for example zappos.com). Trustpilot pages are named after the website, so the Actor finds the page on its own. If a company uses a different name on Trustpilot, open its Trustpilot page and paste that link instead.

How many reviews can I get for one company?

Up to 1,000 per run with all star ratings (200 for each star value), because Trustpilot shows logged-out visitors 10 pages per filter. Add a language or date period, or use Only new reviews on a schedule, to collect more over time.

Does it get reviews in every language?

Yes. Review language is all by default. Set a code such as en or de to keep one language. Every row has a language column.

Is there a Trustpilot reviews API I can call?

Yes, through this Actor. Every run is available through the Apify API (see the code examples above), so you get a Trustpilot reviews API with the same columns for every company.

Do I need a Trustpilot account, an API key or a proxy?

No. The Actor reads public pages without logging in. If Trustpilot blocks the direct connection, it switches to Apify residential proxy on its own, with a hard traffic cap, at no extra charge to you.

Is it legal to scrape Trustpilot reviews?

The Actor reads only public reviews and company information that Trustpilot shows to every visitor. It does not log in, post reviews or collect private account data. Reviews contain personal data such as reviewer names, so check the privacy rules and Trustpilot's terms that apply to how you use the data.
