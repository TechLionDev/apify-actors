Remote Jobs Scraper: RemoteOK, We Work Remotely & Himalayas

Remote jobs scraper for RemoteOK, We Work Remotely, Himalayas, Jobicy and Working Nomads: salary, location, seniority and tags. Free filters and job alerts.

Run it on ApifyAll 23 TechLion Dev Actors$0.80 / 1,000 jobs

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Remote Jobs Scraper collects remote job listings from six popular remote job boards into one clean table: Himalayas, Remote OK, We Work Remotely, Jobicy, Working Nomads and Arbeitnow. You get the job title, company, where the job is open to, employment type, seniority, salary range (also converted to a yearly amount), tags, posting date, job link and the full description as plain text.

It is for job seekers, recruiters, remote job board owners, newsletter writers, sales teams looking for hiring companies, researchers and AI (artificial intelligence) agents.

Every board is read through its own public job feed: no browser, no login and no proxy. Runs are fast, cheap and reliable: 150 fresh jobs from five boards in a few seconds.

  • Build job alerts: search for "python" or "product designer", filter by country and salary, and get only new jobs on a schedule.
  • Fill a remote job board or newsletter with fresh, de-duplicated listings from several sources at once.
  • Find companies that are hiring for sales prospecting and recruiting outreach.
  • Track remote salaries by role, seniority and region.
  • Feed AI tools with clean, plain-text job descriptions.

What data does it extract?
💼 Job title, company and company logo 🌐 Location the job is open to, plus a country/region list
🕒 Employment type (full-time, part-time, contract, freelance, internship) 🎚️ Seniority (intern to executive)
💰 Salary min/max, currency and period 📈 Salary converted to yearly amounts for easy sorting
🏷️ Category and tags/skills 📅 Posted date, days ago and expiry date
🔗 Job link and apply link 📝 Full description as plain text, with word count

Why this scraper?

  • Six boards in one run, with the same columns for every board and duplicates removed (the same job posted on several boards is saved once).
  • Cheaper than other remote job aggregators: $0.80 per 1,000 jobs, with no extra start fee and no charge for filtered-out jobs. Popular alternatives charge $1 to $6 per 1,000.
  • Free filters: posted date, location, employment type, seniority, minimum salary, salary required, include and exclude words, excluded companies.
  • Built-in new-job tracking. Turn on Only new jobs, schedule the Actor, and later runs save only jobs you have not collected yet.
  • No browser, no proxy: official public feeds only, so runs rarely fail.

Input

Pick the job boards, add search terms (optional), and set the filters you need. Leave Search terms empty to get the newest jobs from every board.

Example input:

{
    "sources": ["himalayas", "remoteok", "weworkremotely", "jobicy", "workingnomads"],
    "searchTerms": ["python", "product designer"],
    "maxJobsPerSource": 100,
    "postedSince": "7 days",
    "locations": ["USA", "worldwide"],
    "employmentTypes": ["full-time"],
    "minSalary": 80000,
    "excludeKeywords": ["intern"],
    "onlyNew": true
}
Setting What it does
Job boards Himalayas, Remote OK, We Work Remotely, Jobicy, Working Nomads, Arbeitnow (Europe, includes on-site jobs)
Search terms Job titles, skills or keywords. Each term is searched on every board
Match search terms in Precise (title, category, tags) or Broad (also company and full description)
Max jobs per board and search term Stops each board after this many saved jobs (after filters)
Posted since A date (2026-01-31) or relative value (24 hours, 7 days)
Locations Countries or regions (USA, Europe, Canada, LATAM...). Add worldwide to keep jobs open to anyone
Employment types, seniority Keep only the types and levels you want
Minimum yearly salary, only jobs with a salary Salary filters, using the yearly amount
Include / exclude words, exclude companies Keyword and company filters on title, category and tags
Remove duplicates across boards Save the same company + title only once
Only new jobs + Tracking name Save only jobs not seen in earlier runs

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Choose the job boards and add search terms, or leave them empty for the newest jobs.
  3. Set Max jobs per board and any filters. Filters are free.
  4. Click Start. The default run (30 newest jobs from each of five boards) finishes in a few seconds.
  5. Download the results from the Output tab as Excel, CSV (comma-separated values) or JSON (JavaScript Object Notation), or connect them to another tool.

Job alerts on a schedule

Add your search terms and filters, turn on Only new jobs, and create a schedule (for example every morning). The first run only remembers the current jobs. After that, each run saves only new jobs, so a quiet day costs almost nothing. Connect the dataset to email, Slack or Google Sheets with Apify's integrations.

Frequently asked questions

Do I need an account or API key for these job boards?

No. Every board is read through its own public job feed. The Actor runs on Apify's default infrastructure with no login and no proxy.

Which job board has the most jobs?

Himalayas is by far the largest (over 100,000 remote jobs, searchable). Remote OK, We Work Remotely, Jobicy and Working Nomads publish their newest jobs (from about 35 to a few hundred each). Arbeitnow focuses on Europe and also lists on-site jobs; keep Remote jobs only on to drop those.

How are duplicates removed?

The same job is often posted on several boards. With Remove duplicates across boards on, a job with the same company and title (ignoring case, punctuation and text in brackets) is saved once, from the first board that returned it.

How does the salary filter work?

Salaries are published in many forms (per hour, per month, per year, in different currencies). The Actor keeps the original numbers and also converts them to a yearly amount (hours × 2,080, months × 12...). Minimum yearly salary compares the top of the range with your number. Currencies are not converted.

How are locations matched?

Each job has a location text and a locationRestrictions list (empty means open worldwide). The Locations filter keeps a job when any of your words appears there. Add worldwide to also keep jobs that are open to everyone.

Is it legal to scrape these job boards?

The Actor reads only public job listings through the feeds the boards publish for developers. It does not log in or apply to jobs. Each row keeps the original job link and the board name: if you republish jobs, link back to the original listing and credit the board, as their feed terms ask. You are responsible for how you use the data.
