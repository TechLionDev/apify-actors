WHOIS Lookup: Bulk Domain Expiry, Registrar & DNS

Bulk WHOIS and RDAP domain lookup: registrar, creation and expiry dates, availability, owner country, name servers, MX, SPF and DMARC. Change alerts.

Run it on ApifyAll 23 TechLion Dev Actors$0.50 / 1,000 domains

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

WHOIS Lookup checks any list of domains in bulk and returns one clean row per domain: registrar, creation date, expiry date, days until expiry, domain age, availability, status codes, name servers, DNSSEC and the owner's organization and country when the registry publishes them. It also adds DNS and email security records: server addresses, mail servers with the email provider name (Google Workspace, Microsoft 365, Zoho Mail...), SPF and DMARC policy.

It is for domain investors, marketers, sales teams, IT and security teams, brand protection, and AI (artificial intelligence) agents.

It uses RDAP (Registration Data Access Protocol), the official modern replacement for WHOIS that every domain registry publishes, and falls back to classic WHOIS for country domains without RDAP. DNS answers come from public DNS resolvers. There is no browser, no login, no API key and no proxy, so it is fast and cheap: about 150 domains in 10 seconds.

  • Check domain name ideas in bulk and keep only the available ones.
  • Never miss a renewal: find domains that expire within 30, 60 or 90 days.
  • Spot new businesses: keep only domains registered in the last N days.
  • Enrich lead lists: paste website addresses or email addresses and learn each company's email provider, domain age and registrar.
  • Monitor changes: get told when a domain changes registrar, expiry date, owner, name servers or mail servers.

What data does it extract?
✅ Availability (registered, available) 🏢 Registrar, registrar IANA ID, website and abuse contacts
📅 Created, updated and expiry dates ⏳ Domain age (days and years), days until expiry, expiring-soon flag
🔒 Registry status codes and DNSSEC 🖥️ Name servers
👤 Owner organization, country, state and email when published 🕶️ Privacy-protected flag
📍 A and AAAA records (server addresses) 📧 MX records and email provider name
🛡️ SPF, DMARC and DMARC policy, TXT records 🔁 Changed fields and a plain change summary (monitoring)

Input

The only required field is Domains: one per line. Domains, website addresses and email addresses all work.

Example input:

{
    "domains": [
        "example.com",
        "https://www.wikipedia.org/",
        "info@bbc.co.uk",
        "my-new-bakery-idea-2026.com"
    ],
    "includeDns": true,
    "expiringWithinDays": 90,
    "onlyChanges": false
}

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Paste your domains, website addresses or email addresses into Domains.
  3. Pick options and filters. Filters are free.
  4. Click Start. The default run (4 domains) finishes in a few seconds.
  5. Download the results from the Output tab as Excel, CSV (comma-separated values) or JSON (JavaScript Object Notation), or connect them to another tool.

Monitoring domains on a schedule

Turn on Only changed domains, then create a schedule (for example every day). The first run saves and remembers every domain. After that, each run saves only domains where the registrar, expiry date, owner organization, name servers, mail servers, server addresses, status or availability changed, with changedFields and a changeSummary such as expiresAt: 2026-12-01 → 2027-12-01. Quiet days cost nothing beyond the tiny start fee.

Frequently asked questions

What is the difference between WHOIS and RDAP?

Both tell you who registered a domain and when. WHOIS is the old text format; RDAP is the modern, structured replacement that registries now must provide. This Actor uses RDAP first and falls back to WHOIS for country domains that have no RDAP server, so you always get the same columns.

Why is the owner's name often empty?

Since privacy rules such as GDPR (General Data Protection Regulation), most registries hide personal owner details. The Actor fills the owner organization and country when the registry or registrar publishes them (often for companies) and sets privacyProtected when the details are hidden.

Is "available" always really available?

available means the registry has no record of the domain. Some registries reserve or block names that are not registered, and premium names can cost more, so confirm with a registrar before you buy.

Which domain endings are supported?

All endings with an official RDAP server (.com, .net, .org, .info, .xyz, .uk, .fr, .nl, .au, .ca, .br, .in, most new endings and many more), plus classic WHOIS for endings such as .de, .it, .eu, .so and .at. A few country registries (for example .ch, .es and .jp) publish little or no data to the public; those rows still get DNS and email records and explain what is missing in whoisError.

Do I need an API key or a proxy?

No. The Actor uses official public registry services and public DNS, and runs on Apify's default infrastructure.

Is it legal to look up WHOIS data?

Yes. Registries publish registration data so that anyone can check who operates a domain. The Actor only reads public data, and it does not register, transfer or change domains. You are still responsible for how you use the data, so check the rules that apply to you.
