Shopify & WooCommerce Scraper: Products, Prices & Stock

Shopify scraper and WooCommerce products scraper: prices, discounts, variants, stock, SKUs and images. Free filters and price-change alerts.

Run it on ApifyAll 23 TechLion Dev Actors$0.50 / 1,000 products

A first test run is usually under a cent. No login to the source site. Pay only for the results you get. Built and maintained by TechLion Dev.

Shopify Scraper also works as a WooCommerce products scraper. It collects every product from any Shopify or WooCommerce online store into one clean table: names, prices, sale prices, discounts, variants (sizes, colors), stock status, SKUs (stock keeping units), images, brands, tags, collections and categories. Paste store website addresses and press Start. The Actor works out which platform each store uses, so you can mix Shopify and WooCommerce stores in one run.

It is for ecommerce teams, price-monitoring tools and catalog builders who need Shopify or WooCommerce product, price and stock data without a login.

It reads the public product feeds that both platforms publish for every store (Shopify's product feed and the WooCommerce Store API, the application programming interface that powers WooCommerce shop pages). There is no browser, no login and no proxy, so runs are fast, cheap and reliable.

  • Monitor competitor prices: schedule a daily run and get only the products whose price or stock changed.
  • Build product feeds and catalogs: export a whole store to Excel, CSV (comma-separated values) or JSON (JavaScript Object Notation).
  • Find deals: keep only products on sale, with the discount already worked out.
  • Research a market: compare brands, price ranges and product types across many stores.
  • Feed AI (artificial intelligence) tools and automations with clean, structured product data.

What data does it extract?
🏷️ Product name, brand and product type 🆔 Product ID, variant ID and SKU
💲 Price, regular price, sale flag and discount % 📊 Lowest and highest variant price
✅ In stock, variants in stock, low-stock count 🎨 Options (size, color...) and every variant
🖼️ Main image and all image links 🗂️ Tags, Shopify collections, WooCommerce categories
⭐ Rating and review count (WooCommerce) 📝 Description as text (and HTML if you want it)
📅 Created, published and updated dates (Shopify) 🔁 Price and stock changes since the last run

Why this scraper?

  • Two platforms in one Actor. Shopify and WooCommerce stores in the same run, with the same columns for both.
  • Half the price of the most-used Shopify scrapers: $0.50 per 1,000 products instead of $1.00, and all filters are free.
  • Built-in price and stock monitoring. Turn on tracking and every row says whether it is new, cheaper, more expensive, back in stock or sold out, with the previous price.
  • Product rows or variant rows. Get one row per product with all variants listed inside it, or one row per size and color with its own price, stock, SKU and image.
  • Keeps going when a store fails. A wrong link or a store that turned its feed off is listed in the run summary, and the rest of the run carries on. Stores that fail are never charged.

Input

The only required field is Stores: one store per line. Any of these work:

  • A store's home page: https://colourpop.com or just colourpop.com
  • A Shopify collection: https://gymshark.com/collections/2-inch (only products in that collection)
  • A WooCommerce category: https://<store>/product-category/shoes/, or the store's own category address such as https://www.nutribullet.com/shop/blenders/
  • A single product: https://colourpop.com/products/<product-name> (Shopify) or https://<store>/product/<product-name>/ (WooCommerce)

Example input:

{
    "stores": [
        "https://colourpop.com",
        "https://gymshark.com/collections/2-inch",
        "https://www.nutribullet.com/shop/blenders/"
    ],
    "maxProductsPerStore": 200,
    "outputLevel": "variant",
    "onlyInStock": true,
    "maxPrice": 100,
    "excludeKeywords": ["gift card"],
    "trackChanges": true
}
Setting What it does
Maximum products per store Stops after this many rows per store. Filtered-out products don't count.
Rows One row per product, or one row per variant.
Filters (free) Keywords to keep or skip, in stock only, on sale only, minimum and maximum price, brands, product types/tags/categories, updated since.
Extra data (free) Plain-text description, HTML description, Shopify collection names.
Price and stock monitoring Track changes between runs, or save only the changes.

How to use it

  1. Click Try for free (an Apify account is free to create).
  2. Paste store addresses into Stores.
  3. Pick Rows (products or variants) and any filters. Filters are free.
  4. Click Start. The default run (30 products from each of 3 stores) takes about 20 seconds.
  5. Download your products from the Output tab, or connect them to another tool (see Integrations).

Monitoring prices and stock on a schedule

Turn on Only save changes, then create a schedule (for example every morning). The first run remembers every product. After that, each run saves only new products and products whose price or stock changed, with changeType and previousPrice columns, so a quiet day costs almost nothing. Use a different Tracking name for each separate watch list.

Frequently asked questions

How do I know if a store uses Shopify or WooCommerce?

You don't need to. Paste the address and the Actor checks both. The platform column and the run summary tell you which one it found. If a store uses neither (for example Magento or a custom shop), the run summary says so and you are not charged for it.

Can I scrape a whole Shopify store?

Yes. Set Maximum products per store high enough (for example 100,000) and the Actor reads the store's full public product list, 250 products per request.

Is there a Shopify products API or WooCommerce products API I can call?

Yes, through this Actor. Every run is available through the Apify API (see the code examples above), so you get one products API for both platforms, with the same columns for every store.

Can I get the exact number of items in stock?

Stores don't publish exact stock counts in their public feeds. You get inStock for every product and variant, variantsInStock on Shopify, and lowStockRemaining on WooCommerce stores that show "only X left".

Why are some columns empty?

Each platform publishes slightly different data. Brands, product types, weights and dates come from Shopify only; ratings, reviews, categories and low-stock counts come from WooCommerce only. The columns are always there so your spreadsheet lines up.

A store failed. Why?

The store may have turned off its public product feed, blocked automated requests, or run on another platform. The exact reason is in RUN_SUMMARY. Failed stores are not charged, and the rest of the run still finishes.

Is it legal to scrape Shopify and WooCommerce stores?

The Actor reads only public product information that stores publish so shoppers and search engines can see it. It does not log in, buy anything or collect personal data. You are still responsible for how you use the data, so check the rules that apply to you.
